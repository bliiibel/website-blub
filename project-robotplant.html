RobotPlant

A plant-care project built with an ESP32 C3 and sensors to help you keep your plants healthy.

RobotPlant

Date: January 2026

RobotPlant is a home plant monitoring system that measures soil moisture, light level, and temperature. It helps me know when to water plants and keeps them alive by sending real-time data through a small display.

What I built

  • ESP32 C3 supermini controller
  • Capacitive soil moisture sensor
  • Light sensor
  • Temperature sensor
  • OLED display and alert system

Skills gained

Embedded systems, sensor wiring, basic Python, microcontroller programming, and hardware prototyping.
